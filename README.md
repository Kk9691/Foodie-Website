Foodie is a frontend food delivery website inspired by popular platforms like Zomato and Swiggy.

This project demonstrates my frontend development skills through a clean user interface and interactive features.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

✨ Features

- Responsive website design
- Food category section
- Restaurant and food browsing interface
- Interactive elements using JavaScript
- Mobile-friendly layout
